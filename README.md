# 🃏 德州扑克在线服务器

## 快速启动

```bash
# 安装依赖
npm install

# 启动服务器
node server.js
```

服务器默认运行在 **http://localhost:3000**

## 让朋友加入

### 本地网络（同一WiFi）
1. 启动服务器后，查看你电脑的局域网IP（例如 `192.168.1.100`）
2. 分享地址给朋友：`http://192.168.1.100:3000?room=myroom`
3. 所有人输入相同房间号即可同桌

### 远程朋友（公网访问）
推荐使用 **ngrok** 内网穿透：
```bash
# 安装 ngrok（https://ngrok.com）
ngrok http 3000
# 会生成类似 https://abc123.ngrok.io 的公网地址
```
或者部署到 Railway / Render / Fly.io 等免费云平台。

## 游戏规则
- 每人初始 **1000 筹码**
- 小盲 10 / 大盲 20
- 标准德州扑克规则
- 至少需要 **2人** 才能开始
- 最多支持 **9人** 同桌

## 操作说明
| 操作 | 说明 |
|------|------|
| 弃牌 | 放弃本局 |
| 过牌 | 不跟注，继续（仅当前注=0时） |
| 跟注 | 跟上当前最高注 |
| 加注 | 拖动滑块选择加注金额 |
| 全押 | 押上所有筹码 |

右上角聊天框可以和朋友实时聊天。
